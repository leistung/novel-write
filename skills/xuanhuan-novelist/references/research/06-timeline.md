# 玄幻小说经典作品时间线

## 一、《诛仙》时间线

### 创作背景
**作者**：萧鼎
**连载时间**：2003-2007年
**平台**：幻剑书盟
**字数**：约120万字

### 作品里程碑
```
2003年
├── 开始连载
├── 碧瑶出场，引发关注
└── 青云门设定展开

2004年
├── 人气飙升
├── 碧瑶之死，引爆讨论
└── 张小凡黑化

2005年
├── 陆雪琪感情线展开
├── 鬼厉身份深化
└── 正邪对立加剧

2006年
├── 进入收尾阶段
├── 最终大战铺垫
└── 各方势力汇聚

2007年
├── 完结
├── 结局引发争议
└── IP价值显现
```

### 影响与意义
- 开创玄幻小说情感线深度
- 打破正邪二元对立
- 推动玄幻小说文学性提升
- 影响后续作品创作方向

## 二、《斗破苍穹》时间线

### 创作背景
**作者**：天蚕土豆
**连载时间**：2009-2011年
**平台**：起点中文网
**字数**：约530万字

### 作品里程碑
```
2009年
├── 4月开始连载
├── "三十年河东，三十年河西"爆红
├── 退婚流开创
└── 人气飙升

2010年
├── 长期霸榜
├── 三年之约高潮
├── 异火收集线展开
└── 粉丝群体扩大

2011年
├── 进入收尾阶段
├── 魂殿决战
├── 5月完结
└── 创造多项记录
```

### 影响与意义
- 确立"废柴逆袭"模式
- 打脸流成为主流
- 确立玄幻小说商业标杆
- 影响一代读者审美
